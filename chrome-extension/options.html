☁️ Cloud storage

อัปโหลด CSV ที่ export ขึ้นที่เก็บไฟล์ของคุณเองโดยอัตโนมัติ ไฟล์ยังดาวน์โหลดลงเครื่องเหมือนเดิม ส่งขึ้นไปเฉพาะ CSV ที่ export เท่านั้น ไม่มี cookie หรือข้อมูลหน้าเว็บ

ทั่วไป

ชื่อโฟลเดอร์ปลายทาง (ใช้ / แยกโฟลเดอร์ย่อยได้)

Redirect URI สำหรับลงทะเบียน OAuth app ทุกเจ้า:

Google Drive

วิธีสร้าง Client ID
  1. Google Cloud Console → เปิด Google Drive API
  2. OAuth consent screen → External, เพิ่มอีเมลตัวเองเป็น test user
  3. Credentials → Create OAuth client ID → Web application
  4. Authorized redirect URIs → วาง Redirect URI ด้านบน

ใช้สิทธิ์ drive.file: extension เห็นเฉพาะไฟล์ที่ตัวเองสร้าง

Dropbox

วิธีสร้าง App key
  1. dropbox.com/developers/apps → Create app → Scoped access → App folder
  2. Permissions → เปิด files.content.write แล้วกด Submit
  3. Settings → OAuth 2 Redirect URIs → วาง Redirect URI ด้านบน
  4. คัดลอก App key มาวาง (ไม่ต้องใช้ App secret)

OneDrive

วิธีสร้าง Client ID
  1. portal.azure.com → App registrations → New registration
  2. Supported account types → รวม personal Microsoft accounts
  3. Redirect URI → platform Web → วาง Redirect URI ด้านบน
  4. Authentication → เปิด Access tokens (implicit flow)
  5. API permissions → Microsoft Graph → Files.ReadWrite.AppFolder

ไฟล์จะอยู่ใน OneDrive → Apps → ชื่อ app ที่ลงทะเบียน

Google Sheet (โพสต์ Facebook Group)

ส่งโพสต์ที่ Save หรือ Export จาก Facebook Group เข้าแท็บ raw_posts ส่งเฉพาะกลุ่มที่เลือกว่า Public เท่านั้น

วิธีติดตั้ง Apps Script
  1. เปิด Google Sheet ปลายทาง → Extensions → Apps Script
  2. วางโค้ดจาก apps-script/Code.gs ในไฟล์ zip (ใน repo คือ integrations/google-sheet/Code.gs)
  3. Project Settings → Script properties → เพิ่ม SECRET เป็นค่าสุ่มยาวๆ และ SPREADSHEET_ID (id ใน URL ของ Sheet)
  4. Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone
  5. คัดลอก URL ที่ลงท้ายด้วย /exec มาวางด้านบน พร้อม secret เดียวกัน
